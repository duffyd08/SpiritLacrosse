🥍 Setup

Connect Supabase · ~5 min
1

Go to supabase.com → sign up free → create a new project.

2

Open SQL Editor in the sidebar, paste and run the SQL below.

3

Go to Storage → New bucket → name it illustrations → check Public bucket.

4

Go to Project Settings → API, copy your Project URL and anon key.

5

Choose an admin password — only you use this to approve/deny submissions.

CREATE TABLE illustrations ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, name text NOT NULL, age integer NOT NULL, affiliation text, description text NOT NULL, image_url text, status text DEFAULT 'pending', created_at timestamptz DEFAULT now() ); ALTER TABLE illustrations ENABLE ROW LEVEL SECURITY; CREATE POLICY "Public read approved" ON illustrations FOR SELECT USING (status = 'approved'); CREATE POLICY "Admin full access" ON illustrations FOR ALL USING (true) WITH CHECK (true); CREATE POLICY "Public insert" ON illustrations FOR INSERT WITH CHECK (true);
